BARDAHL — обновление статистики руководителя и ежедневной очистки очереди

Файлы:
- index.html — обновлённый интерфейс статистики руководителя.
- setup.sql — SQL для Supabase: очистка очереди ежедневно в 20:30 по времени Казахстана (UTC+5), запрет входа в очередь/отметок после 20:30, сохранение истории заказов.
- manifest.webmanifest, sw.js, icon-192.svg, icon-512.svg — файлы PWA.

Установка:
1. Сначала сохраните копию текущих файлов и базы.
2. В Supabase откройте SQL Editor и выполните весь setup.sql. Скрипт рассчитан на повторный запуск для объектов, которые он сам создаёт/обновляет.
3. Проверьте в Supabase Database → Extensions, что pg_cron включён. Если pg_cron недоступен, автоматическая очистка по расписанию не активируется; SQL покажет NOTICE. После включения повторно выполните setup.sql.
4. Замените файлы приложения в новом репозитории GitHub Pages файлами из архива и дождитесь публикации.
5. На телефоне полностью закройте приложение и откройте снова. Если отображается старая версия, обновите страницу в браузере; Service Worker обновится при следующем открытии.

Статистика руководителя:
- За день — дата в поле «Дата отчёта».
- За месяц — месяц выбранной даты.
- За год — год выбранной даты.
- Диапазон дат — поля «С даты» и «По дату».
- Для каждого мастера отображаются число заказов и количество каждой услуги. Цены и суммы не показываются.

Важно:
- SQL не удаляет таблицу work_orders и не очищает историю заказов, поэтому месячная и годовая статистика сохраняется.
- Очередь и отметки кругов удаляются в 20:30 по времени Казахстана. После 20:30 повторно в очередь войти нельзя до следующего дня.
- SQL меняет схему/расписание в Supabase, но не может опубликовать HTML в GitHub Pages автоматически.
