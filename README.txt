BARDAHL — учёт работ и заказов + очередь мастеров

Что изменено
- Мастеру в отчётах показаны заказы, количество услуг и сумма за день, месяц и год.
- После отчётов у мастера отображается «Статистика за день»: список выполненных услуг и жёлтый счётчик количества по каждой услуге.
- У руководителя сверху показываются количество услуг, число заказов и сумма за день, месяц и год.
- Ниже руководитель видит список мастеров: услуги, заказы и итоговую сумму за выбранный период. Кнопки «За день / За месяц / За год» переключают период списка.
- При нажатии на фамилию открываются показатели выбранного мастера за день, месяц и год с суммами, а также список услуг за выбранный день с жёлтыми счётчиками.
- Руководитель может открыть вкладку «Очередь» только для просмотра.
- Мастер сам выбирает позицию и нажимает «Встать в очередь». Фамилия появляется в общей таблице после входа.
- Обновлён кеш PWA, чтобы браузер загрузил новую версию.

Установка файлов приложения
1. На компьютере откройте новый репозиторий BARDAHL на GitHub.
2. Распакуйте архив и загрузите файлы из папки bardahl_revision в корень репозитория, заменив одноимённые файлы.
3. Сохраните изменения (Commit changes) и дождитесь обновления GitHub Pages.
4. На iPhone закройте приложение. Откройте сайт в Safari и обновите страницу, затем откройте значок BARDAHL снова.

ВАЖНО: обновление существующего Supabase
Откройте Supabase → SQL Editor, вставьте содержимое queue-entry-fix.sql и нажмите Run. Этот небольшой SQL исправляет фамилию «Овчинников» в функции входа в очередь. Полный setup.sql повторно запускать только ради этой правки не требуется.

В архиве также лежит setup.sql с исправленным написанием фамилии для полной установки/резервной копии. Не запускайте полную схему без необходимости, если приложение уже работает.
