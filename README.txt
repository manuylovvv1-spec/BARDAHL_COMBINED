BARDAHL — очередь по боксам

Что изменено:
- При вставании в очередь мастер сначала выбирает бокс № 1–9, затем позицию № 1–9 в общей очереди.
- Каждая позиция в очереди уникальна для всех боксов: если позиция № 1 занята, другой мастер не сможет выбрать её даже в другом боксе.
- В общей таблице очереди фамилии мастеров не отображаются: видны только бокс, позиция и отметки услуг.
- Учёт работ, заказы, роли, отметки кругов и остальные функции сохранены.
- Кэш PWA обновлён до bardahl-combined-v12.

Установка:
1. Сначала откройте Supabase → SQL Editor и выполните queue-global-position.sql. Скрипт сделает позиции уникальными для всей очереди и обновит серверную проверку, чтобы нельзя было занять чужую позицию.
2. Замените файлы приложения в корне GitHub Pages файлами из архива.
3. Дождитесь публикации сайта. На iPhone полностью закройте приложение и откройте снова.

Если разворачиваете базу с нуля, используйте setup.sql.
