BARDAHL — очередь по боксам

Что изменено:
- При вставании в очередь мастер сначала выбирает бокс № 1–9, затем позицию № 1–9 в общей очереди.
- Каждая позиция в очереди уникальна для всех боксов: если позиция № 1 занята, другой мастер не сможет выбрать её даже в другом боксе.
- В общей таблице очереди фамилии мастеров не отображаются: видны только позиция, бокс и отметки услуг.
- Отметки услуг загружаются без фильтра по роли, поэтому сохранённые услуги видны всем пользователям.
- Учёт работ, заказы, роли, отметки кругов и остальные функции сохранены.
- Кэш PWA обновлён до bardahl-combined-v13.

Установка:
1. Откройте Supabase → SQL Editor и выполните queue-global-position.sql, если этот скрипт ещё не выполняли. Он делает позиции уникальными для всей очереди.
2. Выполните fix-service-log-visibility.sql в Supabase → SQL Editor. Это восстановит чтение журнала услуг для гостя и остальных ролей, если права ранее были ограничены.
3. Замените файлы приложения в корне GitHub Pages файлами из архива.
4. Дождитесь публикации сайта. На iPhone полностью закройте приложение и откройте снова.

Если разворачиваете базу с нуля, используйте setup.sql.
