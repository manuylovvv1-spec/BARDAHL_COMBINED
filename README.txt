BARDAHL — учёт работ и очередь мастеров

Изменения в этой версии:
- прайс содержит услуги строго в заданном порядке; названия в выпадающем списке отображаются без цен;
- при выборе услуги её цена подставляется в отдельное редактируемое поле; для «Услуга СТО» название и цена вводятся вручную;
- статистика мастера оставлена без изменений;
- в статистике руководителя доступны периоды «За день», «За месяц», «За год»;
- общая статистика показывает список мастеров, количество услуг, количество заказов и сумму по каждому, а также общий итог;
- нажатие на фамилию открывает подробную статистику мастера за тот же период: услуги и цены, список заказов с автомобилями, работами и итогами; кнопка «Назад» возвращает к списку всех мастеров;
- очередь очищается по расписанию в 20:30 по времени Казахстана (UTC+5); история заказов не удаляется.

Установка обновления:
1. Распакуйте архив на компьютере.
2. Скопируйте файлы в корень нового репозитория GitHub, заменив одноимённые файлы.
3. Сохраните изменения (Commit changes) и дождитесь обновления GitHub Pages.
4. На iPhone закройте приложение и откройте заново. Если отображается старая версия, откройте сайт в Safari и обновите страницу; затем снова запустите иконку на экране.

Важно:
- Обновление касается прайса и статистики руководителя. Статистика мастера и остальные функции приложения не менялись намеренно.
- setup.sql приложен для справки/полного комплекта. Для этих изменений SQL повторно запускать не требуется: новые таблицы не добавляются.
- Перед публикацией проверьте, что в GitHub используется новый репозиторий BARDAHL, а не один из прежних отдельных проектов.


Дополнительное обновление отчётов и руководителя:
- У мастера в отчётах снова отображается сумма за день, месяц и год вместе с числом заказов и услуг.
- У руководителя в статистике показываются только выполненные услуги и их количество жёлтым цветом; разделы заказов, выполненных работ и суммы скрыты.
- Руководителю доступна вкладка «Очередь» только для просмотра: нельзя менять позицию, входить/выходить из очереди, сохранять или удалять услуги, сбрасывать очередь.
- Обновлён номер кеша PWA, чтобы устройства загрузили новую версию.
