BARDAHL — очередь мастеров (версия без статистики)

Файлы:
- index.html — приложение
- setup.sql — схема и функции Supabase
- manifest.webmanifest, sw.js — установка PWA и кеш
- icon*.svg — иконки

Что работает:
1. Очередь фиксированных позиций 1–9; занятые позиции недоступны.
2. После выбора позиции панель выбора места скрывается; позицию можно изменить отдельной кнопкой.
3. Таблица показывает только кружки: одна сохранённая услуга зажигает один зелёный кружок, несколько услуг — несколько кружков. Названия услуг в таблице не выводятся.
4. АКПП, Антифриз и Халдекс выбираются в панели мастера. После «Сохранить услуги» общая таблица обновляется для всех пользователей.
5. Статистики и панели подсчёта нет.
6. В начале нового календарного дня по времени Asia/Almaty при первом входе очередь, отметки и круг сбрасываются автоматически. История услуг за предыдущие дни не сохраняется в базе.

Установка:
1. Supabase → SQL Editor: выполните setup.sql целиком. Перед запуском на рабочей базе проверьте скрипт; функция ежедневного сброса удаляет строки очереди и отметок предыдущего дня.
2. Загрузите все файлы из архива в корень репозитория GitHub Pages, заменив старые.
3. Откройте приложение заново. Если старая версия осталась в iPhone, закройте её и откройте ссылку GitHub Pages ещё раз.

Примечание: код и SQL подготовлены, но не проверены на живой базе Supabase.


Сброс кругов менеджером
- Войдите как «Менеджер».
- Нажмите «Сбросить очередь» и подтвердите действие.
- Все зелёные отметки будут очищены, счётчик круга вернётся к 1. Мастера и их занятые позиции останутся в очереди.
- Для работы кнопки выполните обновлённый setup.sql в Supabase SQL Editor.
Удаление услуги: у менеджера кнопка × отображается у всех сохранённых услуг. У мастера она отображается только рядом с его собственными услугами. Перед удалением запрашивается подтверждение. Для включения выполните обновлённый setup.sql в Supabase и замените файлы на GitHub Pages.
