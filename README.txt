BARDAHL — очередь по боксам

Что изменено:
- При вставании в очередь мастер сначала выбирает бокс № 1–9, затем позицию № 1–9 внутри выбранного бокса.
- Одна и та же позиция может быть занята в разных боксах; в одном боксе одинаковая позиция занята только одним мастером.
- В общей таблице очереди фамилии мастеров не отображаются: видны только бокс, позиция и отметки услуг.
- Учёт работ, заказы, роли, отметки кругов и остальные функции сохранены.
- Кэш PWA обновлён до bardahl-combined-v10.

Установка:
1. Сначала откройте Supabase → SQL Editor и выполните queue-box-migration.sql.
   Существующие занятые позиции будут сохранены и перенесены в бокс № 1.
2. Замените файлы приложения в корне GitHub Pages файлами из архива.
3. Дождитесь публикации сайта. На iPhone полностью закройте приложение и откройте снова.

Если разворачиваете базу с нуля, используйте setup.sql.
