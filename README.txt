BARDAHL — исправление выравнивания и ежедневной очистки очереди

Что изменено:
- Подпись «ОЧЕРЕДЬ · УЧЁТ РАБОТ И ЗАКАЗОВ» выровнена по центру.
- Заголовки разделов выровнены по центру.
- Версия кэша PWA увеличена до bardahl-combined-v8.
- Добавлен queue-reset-2030.sql для установки расписания автоматической очистки очереди в 20:30 по времени Казахстана (15:30 UTC).

Остальные функции приложения сохранены.

Установка:
1. Замените файлы приложения в корне репозитория GitHub файлами из архива.
2. Дождитесь публикации GitHub Pages.
3. В Supabase SQL Editor запустите queue-reset-2030.sql один раз, чтобы установить/переустановить ежедневное расписание. Если pg_cron не включён, включите расширение pg_cron в Supabase Database > Extensions и запустите скрипт снова.
4. Не запускайте setup.sql целиком для этого исправления.
5. Закройте приложение на iPhone и откройте заново.

В 20:30 очищается состав очереди и отметки очереди. Заказы и отчёты в разделе учёта работ не удаляются. После очистки мастера могут сразу снова вставать в очередь.
